# the lean release tree). export_tree.py --public refuses when a file the intel-free-mfg package or the libxess_fg.dll and
# libxefg_wave.so build records read is missing, imports every exported release/ tool in the export and runs the
# installer tests there. It writes public versions of the C sources (resolved for the public build's configuration),

# only, so release/assemble.py with no --variant builds it); a header that holds nothing in that configuration is not
# listed here and is left out of the export together with its #include lines. It also writes the files GitHub shows for
# a repository, which this list must not name: README.md, LICENSE and NOTICE.md at the top and SECURITY.md and
